# Movie Recommendation

A small command-line program that suggests movies based on your preferences. It asks about movie themes and genres, then prints recommendations from its built-in lists.

## Requirements

- Python 3
- No third-party packages

## Run the program

From the project directory, run:

```bash
python3 "Movie Recommendation.py"
```

Answer each prompt with `y` for yes. Any other response is treated as no. The program prints your recommendations when all questions have been answered.

## Project structure

| File | Description |
| --- | --- |
| `Movie Recommendation.py` | Interactive questionnaire and movie recommendation logic |

## Customization

The questions, preference-matching logic, and movie lists are defined directly in `Movie Recommendation.py`. Edit that file to adjust the questionnaire or recommendations.
